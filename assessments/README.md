# Checkpoint assessments

The catalog schedules CP-00 through CP-18, one checkpoint per level. None has been
issued. Prepare a checkpoint only after its named prerequisite passes, using
[the checkpoint template](../templates/checkpoint.md) and
[assessment rules](../docs/assessment.md).

Every checkpoint includes theory, prediction, debugging, coding, problem solving,
previous concepts, and a mini project. A checkpoint requires 85/100 plus verified
mastery. Keep the answer key private. A failed checkpoint blocks the next level.
