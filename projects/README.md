# Project milestones

Projects are planned requirements, not learner implementations. None is assigned.
Prepare each from [the project template](../templates/project.md) only when its
catalog prerequisite passes. The [roadmap](../curriculum/roadmap.md) gives IDs and
time budgets. Each project gates its level checkpoint.

| Level | ID | Project | Integration focus |
|---|---|---|---|
| 1 | PRJ-001 | Calculator | Input, types, arithmetic; no branches/loops yet |
| 2 | PRJ-002 | Number guessing game | Conditions, loops, bounded attempts |
| 3 | PRJ-003 | Contact manager | In-memory collections and data choices |
| 4 | PRJ-004 | Student marks system | Functions, records, boundary cases |
| 6 | PRJ-005 | Expense tracker | JSON/CSV persistence and documented data |
| 7 | PRJ-006 | File organizer | Paths, failure handling, preview on sample files |
| 8 | PRJ-007 | CLI application | Modules, entry points, object design where useful |
| 12 | PRJ-008 | Log analyzer | Parsing, automated tests, logs, refactoring |
| 13 | PRJ-009 | Database-backed application | CRUD, transactions, migrations |
| 14 | PRJ-010 | API client and REST API | Pagination, authentication configuration, service behavior |
| 15 | PRJ-011 | Concurrent API collector | Bounded tasks, timeouts, cancellation |
| 16 | PRJ-012 | Linux server checker and SSH tool | Read-only health checks on controlled hosts |
| 17 | PRJ-013 | Docker and Kubernetes health checker | Inventory reports and mocked integrations |
| 18 | PRJ-014 | AWS inventory and deployment planner | Read-only inventory and reviewed deployment planning |

Provide problem, requirements, expected behavior, constraints, sample input/output,
planning deliverables, and evaluation criteria. Raajashree designs the solution.
Do not supply a finished program. Assess new integration, not repetition of a
teaching example. Detailed requirements remain pending until the learner is ready.

CAP-001 follows CP-18 and uses [the capstone plan](../docs/capstone.md).
