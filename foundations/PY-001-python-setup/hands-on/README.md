# PY-001 — Hands-on challenge: Prove your setup

## Problem

Naresh wants proof that Raajashree's Python is installed correctly *and* that she understands the proof.

## Requirements

Produce `hands-on/challenge.md` containing, in this order:

1. **Plan (before you run anything).** Problem, inputs, outputs, constraints, edge cases, and your intended approach in plain sentences.
2. **Evidence.** For each of these, the exact command and exact reply:
   - interpreter version
   - pip version
   - a one-line Python instruction (using `-c`) that prints the text `Setup verified by <your name>`
   - a command that shows **where** your Python is installed. Find out for yourself how to do this on your OS (Windows or Ubuntu) (searching the web is allowed; write what you searched and what you learned).
3. **Reflection.** Tests you ran, anything that failed and how you fixed it, and what you would improve.

## Boundaries

- Do not paste another person's setup note.
- If a command fails, include the failing output too — that is useful evidence.
- Sample shape only: a good evidence line looks like
  `command: <what you typed>` then `reply: <what came back>`.
